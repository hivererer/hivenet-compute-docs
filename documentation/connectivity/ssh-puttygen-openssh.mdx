## What you’ll need

- A Compute instance with your SSH public key uploaded
- **Windows 10 or later**
- Windows Terminal / PowerShell (OpenSSH)

## OpenSSH via Windows Terminal

###  Step 1 – Check OpenSSH is installed

Open PowerShell and run:

```
ssh -V
```

You should see an OpenSSH version. If not, enable it:

1. Settings → Apps → Optional features
2. Add a feature → OpenSSH Client

###  Step 2 – Create or convert your key

If you already have an OpenSSH private key, use it directly with Windows OpenSSH.

If your key is in PuTTY's `.ppk` format:

1. Open PuTTYgen and load the private key.
2. Select **Conversions → Export OpenSSH key**.
3. Save the exported private key and use its path with `ssh -i` or `IdentityFile` below.

For a new key pair, follow [Add an SSH key on Windows](/documentation/connectivity/ssh-key-windows). Add only the public key to Compute.

### Step 3 – Create a config entry (optional)

In `C:\Users\<you>\.ssh\config`, add:

```text
Host hivenet
    HostName YOUR_SSH_HOST
    User YOUR_SSH_USER
    IdentityFile ~/.ssh/id_ed25519
    Port 22
```

Replace `YOUR_SSH_HOST` and `YOUR_SSH_USER` with the values in the instance’s SSH connection details, and use your matching private key. Include any additional settings supplied by the console. See [SSH configuration and host verification](/tutorials/more-guides/SSH-config-file-explained).

Save, then simply:

```
ssh hivenet
```

###  Step 4 – Connect manually

Without a config file, run:

```text
ssh -i ~/.ssh/id_ed25519 YOUR_SSH_USER@YOUR_SSH_HOST
```

Use the username and hostname from the console and the private key matching your uploaded public key.

##  Troubleshooting OpenSSH

- **Permission denied** → Wrong key or not uploaded
- **Connection timed out** → Check internet/firewall
- **Unknown host** → Typo in instance ID

## Common PuTTY pitfalls

- **Server unexpectedly closed connection** → Wrong port or host name
- **No supported authentication methods available** → Wrong key format
- **Support modern encryption and OpenSSH compatible formats**
