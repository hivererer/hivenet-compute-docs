This guide takes you from the Compute console to a working inference request. You’ll choose a location, model, and variant, set a fixed replica count, name the endpoint, create an API key, and use the generated quick-start snippet to call it.

<Info>
  ## What you’ll need

  - A Compute account
  - Access to a Compute organization
  - Enough credits in the organization balance for the endpoint you choose
  - Python, Node.js, or a terminal with `curl` if you want to test the endpoint locally

  Inference API uses the same organization balance as your Compute resources.
</Info>

<Steps>
  <Step title="Open Inference API">
    1. Sign in to the [Compute console](https://console.hivecompute.ai/).
    2. Confirm the organization shown in the upper-left corner.
    3. Open **Inference API** from the left sidebar.
    4. Select **New deployment**.

    The endpoint and any API keys you create belong to the active organization.
  </Step>
  <Step title="Choose a location">
    Choose where you want the endpoint to run.

    The current production flow asks for location first. The console can show available options such as France, UAE, or Global, and can mark locations **Sold out** when capacity is unavailable.

    The location notice also explains how prompts and responses are handled for the selected region. Read it before continuing.
  </Step>
  <Step title="Choose a model">
    Select one of the models available for that location.

    Each model card can show:

    - A short description
    - Capability tags
    - A starting hourly price

    Select **All models** to browse beyond the initial set shown on the page.
  </Step>
  <Step title="Choose a model variant">
    After selecting a model, choose one of its available variants.

    A variant fixes the serving configuration for that endpoint. Depending on the model, the console can show details such as:

    - GPU type and count
    - Quantization
    - Context window
    - Time to first token
    - Inter-token latency
    - Output speed
    - License

    <Info>
      The live console is the source of truth for the variant details and price you are actually deploying.
    </Info>
  </Step>
  <Step title="Choose the number of replicas">
    Set how many replicas you want to run.

    Each replica is a parallel copy of the model endpoint. More replicas can increase request capacity, but each replica increases the hourly cost.

    <Note>
      Autoscaling is not available in the current production version. Choose the fixed number of replicas you want to run.
    </Note>
  </Step>
  <Step title="Name your endpoint">
    Keep the suggested endpoint name or enter your own.

    Use lowercase letters, numbers, and hyphens. The endpoint name is the label you use to manage it in the console. It is not the model name you pass in API requests.
  </Step>
  <Step title="Review the cost and deploy">
    Review the selected model, location, replicas, and estimated cost.

    The review section shows the current:

    - Total cost per hour
    - Estimated cost per 24 hours
    - Estimated cost per week

    Select **Deploy model** when you’re ready.

    The endpoint moves to **Starting** while Hivenet prepares it. The production UI says this takes about 90 seconds. Charges begin once the endpoint is **Running**.
  </Step>
  <Step title="Create an API key">
    Create a key if the organization does not already have one you want to use.

    1. In **API keys**, select **New key**.
    2. Enter a unique label using lowercase letters, numbers, and hyphens.
    3. Select **Create**.
    4. Copy the full API key and store it securely.
    5. Select **Copy and close** only after you have saved the key.

    <Warning>
      The full API key is shown once. You won’t be able to view it again after closing the dialog.
    </Warning>
  </Step>
  <Step title="Open the endpoint details">
    When the endpoint reaches **Running**, open its details from the **Deployments** list.

    The details view can include:

    - Endpoint URL
    - Model
    - GPU and quantization
    - Context window
    - License
    - Region
    - Cost so far and current hourly rate
    - Replica count
    - Requests per hour
    - Inter-token latency
    - Tokens in and out over 24 hours
    - Output speed
    - Quick-start snippets for Python, JavaScript, and `curl`

    <Warning>
      Copy the endpoint URL exactly as shown. It already contains the API version path, such as `/v1`. Do not add another `/v1`.
    </Warning>
  </Step>
  <Step title="Send your first request">
    The safest way to call an endpoint is to copy the generated snippet from its details view. The snippet contains the exact endpoint URL and served model name.

    For Python, install the OpenAI SDK:

    ```bash
    pip install openai
    ```

    Then use the values from your endpoint:

    ```python
    from openai import OpenAI
    
    client = OpenAI(
        base_url="YOUR_ENDPOINT_URL",
        api_key="YOUR_INFERENCE_API_KEY",
    )
    
    response = client.chat.completions.create(
        model="YOUR_SERVED_MODEL_NAME",
        messages=[
            {"role": "user", "content": "Hello!"}
        ],
    )
    
    print(response.choices[0].message.content)
    ```

    Or use `curl`:

    ```bash
    curl YOUR_ENDPOINT_URL/chat/completions \
      -H "Authorization: Bearer YOUR_INFERENCE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "YOUR_SERVED_MODEL_NAME",
        "messages": [{"role": "user", "content": "Hello!"}]
      }'
    ```

    <Tip>
      Do not substitute your endpoint name or the catalog title for `YOUR_SERVED_MODEL_NAME`. Copy the exact `model` value generated by the console.
    </Tip>
  </Step>
</Steps>

## What happens after deployment

Your endpoint stays online and continues using organization credits while it is running.

From the deployment menu or details view, you can later:

- Change the fixed replica count when capacity allows
- Stop the endpoint and start it again later
- Retry failed replicas when the action is available
- Permanently terminate the endpoint
- Clear a terminated endpoint from the list

Stopping is reversible. Termination is permanent. **Clear** only removes the already-terminated entry from the list.

## Troubleshooting

### A location is sold out

That location does not currently have enough free capacity for another endpoint. Choose another available location or try again later.

### Fewer replicas are available than you expected

Current regional capacity can limit how many replicas you can run. Use the maximum offered by the console or check again later.

### The endpoint is still Starting

The production UI says endpoint creation takes about 90 seconds. Wait for **Running** before sending requests.

### The API request returns an authentication error

Check that you are using an **Inference API key**, not a Compute public API token or your console session credentials. Also confirm that the key is still **Active**.

### The API request cannot find the model

Use the exact `model` value from the endpoint’s generated quick-start snippet. The served model name can differ from the catalog title and endpoint name.

### The organization does not have enough credits

Add credits before deploying or restarting the endpoint. If you cannot manage the organization balance yourself, ask the organization Owner to add credits.
