Use the **Deployments** section of Inference API to monitor and control the model endpoints your organization has created.

Each row shows the endpoint status, name, model, region, replica count, recent request count when available, and current hourly cost.

## Open endpoint details

Open an endpoint's options menu and select **Details**.

Depending on the endpoint state, the details view can include:

- Endpoint URL
- Model
- GPU and quantization
- Context window
- License
- Region
- Cost so far and current hourly rate
- Creation or stop time
- Replica count
- Requests per hour
- Inter-token latency
- Tokens in and out over 24 hours
- Output speed
- Quick-start snippets for Python, JavaScript, and `curl`

The endpoint URL can also be copied from the deployment list.

## Endpoint states

| State | What it means | What you can usually do |
| --- | --- | --- |
| **Starting** | Hivenet is provisioning the endpoint. | Wait for it to become ready, or use the available management actions. |
| **Running** | The endpoint is serving requests. | Call it, change replicas, stop, or terminate. |
| **Partially running** | Some requested replicas are serving and others are not. | Keep serving with reduced capacity, retry when available, change replicas, stop, or terminate. |
| **Stopped** | The endpoint is offline and its configuration is retained. | Start or terminate it. |
| **Error** | The endpoint is not currently serving. | Retry failed replicas when available, stop, or terminate. |
| **Terminated** | The endpoint is permanently shut down. | Clear it from the list. |

## Stop an endpoint

Use **Stop** when you want to take an endpoint offline but may need the same configuration again.

1. Open the endpoint options menu.
2. Select **Stop**.
3. Review the confirmation message.
4. Confirm the action.

The replicas are torn down and the endpoint stops serving requests. Serving charges stop once the endpoint is stopped.

<Info>
  Stopping preserves the endpoint configuration. Starting it later still depends on enough capacity being available in the same region.
</Info>

## Start a stopped endpoint

1. Open the options menu for a **Stopped** endpoint.
2. Select **Start**.
3. Review the endpoint details.
4. Confirm the start.

The endpoint moves to **Starting** and begins serving once it reaches **Running**.

If the organization balance does not have enough credits, the console blocks the start and asks for more credits.

## Retry failed replicas

A **Retry** action can appear for **Partially running** or **Error** endpoints.

Use it to ask Hivenet to retry failed replicas. Retry does not change a deliberately stopped endpoint into a running one; use **Start** for an endpoint that is **Stopped**.

## Terminate an endpoint

Termination permanently removes the endpoint from service.

1. Open the endpoint options menu.
2. Select **Terminate**.
3. Confirm that you understand the endpoint will stop accepting requests and cannot be started again.
4. Confirm the termination.

After termination:

- Requests to the endpoint fail.
- The endpoint URL is no longer usable.
- The endpoint cannot be started again.
- Hourly charges stop once termination is complete.

<Warning>
  Update applications that depend on the endpoint before terminating it. Termination is permanent.
</Warning>

## Clear a terminated endpoint

After an endpoint is **Terminated**, you can use **Clear** to remove the terminated entry from the deployment list.

Clearing does not terminate a running endpoint and does not affect an endpoint that still exists. It is only a cleanup action for an already-terminated entry.

## Partially running endpoints

An endpoint becomes **Partially running** when fewer replicas are actively serving than requested.

The endpoint can still accept requests, but its available throughput is reduced. You can retry failed replicas when the action is available, reduce the replica count, wait for recovery, or stop the endpoint.
