Hivenet Inference API uses the same prepaid organization credit balance as Compute.

You pay for the fixed model-serving capacity you run. The console shows the current cost before deployment and while the endpoint is active.

## How cost is calculated

A model variant has an hourly price per replica. Your displayed endpoint rate is based on the selected variant and replica count.

Increasing the replica count raises the endpoint's hourly rate. Reducing it lowers the rate once the change takes effect.

The deployment review screen also shows estimated cost over 24 hours and one week before you deploy.

<Info>
  Prices shown in the console are the current source of truth. Use the review screen rather than an old screenshot or saved estimate when creating a new endpoint.
</Info>

## When charging starts

A new or restarted endpoint enters **Starting** while Hivenet provisions its replicas.

The current production UI says starting a model takes about 90 seconds. Charges begin once the endpoint is running.

## When charging stops

When you stop an endpoint, Hivenet tears down its replicas and serving charges stop once the endpoint reaches **Stopped**.

When you terminate an endpoint, hourly charges stop once termination is complete.

<Warning>
  Disabling or revoking an Inference API key does not stop an endpoint. The serving capacity stays online and charges continue.
</Warning>

## Changing replica count

The current production version uses a fixed replica count. Increasing replicas increases hourly cost; reducing them lowers it after the change takes effect.

Current regional capacity can limit how many replicas you are allowed to run.

See [Manage replicas and capacity](/documentation/inference-api/replicas-and-capacity) for how fixed scaling works.

## Stopped endpoints

A stopped endpoint keeps its configuration but has no running replicas.

You can start it again later if enough capacity is available in the same location. Charges resume when the endpoint is running again.

Stopping is useful when you expect to reuse the endpoint but do not need it continuously.

## Organization credits

Inference API and Compute resources draw from the same organization balance.

If there are not enough credits to deploy or restart an endpoint, the console blocks the action and asks for more credits. If you cannot add credits yourself, ask the organization Owner to top up the balance.

See [Billing information](/documentation/account-billing/billing-info) for payment methods, auto top-up, invoices, and organization billing roles.

## Monitor current spend

The Inference API page can show organization-level 24-hour spend and each active endpoint's current hourly cost.

You can also use the main Compute billing and spending views to understand the shared organization balance.

See [Track organization spending in real time](/documentation/account-billing/track-costs-real-time).

## Cost is based on serving capacity

The current Inference API product is priced around the replicas you run rather than the number of tokens sent in each request.

Sending fewer requests does not automatically reduce the replica count or hourly rate. Autoscaling is not available in the current production version.

If you no longer need the capacity, reduce the replica count or stop the endpoint.
