Use this page when an endpoint cannot start, is only partially running, or an API request fails.

## A location is sold out

The current production flow asks you to choose a location before choosing a model.

A location marked **Sold out** cannot accept another endpoint at that moment. Choose another available location or try again later.

The console is the source of truth for current regional capacity.

## A model or variant is unavailable

Model and variant availability depends on the selected location and current infrastructure capacity.

Try one of these options:

- Choose another available model or variant.
- Choose another location.
- Reduce the replica count if the console allows it.
- Try again later after capacity has been released.

## The organization does not have enough credits

The console blocks deployment or start actions when the organization does not have enough credits.

Add credits when the option is available, or ask the organization Owner to top up the balance if you do not have billing permissions.

Inference API and Compute resources use the same organization balance.

## The endpoint is still Starting

The current production UI says starting a model takes about 90 seconds.

While the endpoint is **Starting**, it is not ready for normal traffic yet. Wait for **Running** before testing your integration.

If it remains in **Starting** well beyond the expected period, note the endpoint name, model, region, and approximate start time before contacting Support.

## The endpoint is Partially running

**Partially running** means some requested replicas are serving and others are not.

The endpoint can still accept traffic, but available throughput is lower than the configured capacity.

You can:

1. Use **Retry** when the action is available.
2. Reduce the replica count if your workload can run with less capacity.
3. Wait for capacity to recover.
4. Stop the endpoint if you do not want it serving with reduced capacity.

## The endpoint is in Error

**Error** means the endpoint is not currently serving normally.

Start with these checks:

1. Use **Retry** if the action is available.
2. Check whether the selected location still has capacity.
3. Check that the organization has enough credits.
4. If the problem continues, collect the endpoint name, region, model, and approximate failure time before contacting Support.

## Retry is unavailable

The **Retry** action is shown only when it applies to the endpoint's current state.

If the action is unavailable, wait for the state to update or use another management action appropriate to the endpoint, such as **Start** for a stopped endpoint.

Retry does not guarantee recovery if the underlying infrastructure condition still exists.

## A replica change cannot be saved

Capacity can change while you are editing an endpoint.

If the requested replica count is no longer available, reduce it to the maximum currently offered by the console or try again later.

## A stopped endpoint will not start

Starting a stopped endpoint requires:

- Enough organization credits
- Enough current capacity for its existing configuration

If the console reports insufficient credits, add credits first. If capacity is unavailable, wait or create another endpoint using an available configuration.

## The API key is rejected

Check that:

- You are using an **Inference API key**, not a Compute public API token.
- The key is **Active** rather than disabled or revoked.
- The key belongs to the same organization as the endpoint.
- The request sends the key as a bearer token.

If the secret was lost or revoked, create a new key and update the application.

See [Create and manage Inference API keys](/documentation/inference-api/api-keys).

## The endpoint URL does not work

Copy the URL from the endpoint details or from the copy control in the deployment list rather than reconstructing it manually.

The endpoint already includes the API version path, such as `/v1`. Do not add a second `/v1`.

For chat completions, the generated `curl` example calls:

```text
YOUR_ENDPOINT_URL/chat/completions
```

## The request cannot find the model

Do not assume the endpoint name or catalog title is the model identifier expected by the API.

Copy the exact `model` value from the endpoint's generated **Quick-start snippets**.

## Requests are slower than expected

Check:

- Whether the endpoint is **Partially running**.
- How many replicas are currently serving.
- The request shape, especially long prompts or large outputs.
- The inter-token latency and output-speed metrics in the endpoint details.

The requests-per-minute estimate shown with a model variant is a planning estimate for that serving configuration, not a guarantee for every prompt shape.

## A terminated endpoint still appears

Termination permanently shuts down the endpoint, but the terminated record can remain visible in the deployment list.

Use **Clear** to remove an endpoint that is already **Terminated** from the list.

**Clear** does not terminate an active endpoint. It only removes the already-terminated record.

## What to send Support

If you still need help, include:

- Organization name
- Endpoint name
- Model and variant
- Location
- Endpoint status
- Replica count
- Approximate time the problem started
- What action you were trying to perform

Do not send your full API-key secret.
